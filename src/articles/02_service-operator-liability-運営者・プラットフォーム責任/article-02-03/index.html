FILE 02-03: The Pirate Bay創設者裁判――世界最大級トラッカーサイトの末路

事件概要

スウェーデンで2003年に設立された世界最大級のトレントトラッカーサイト「The Pirate Bay」の創設者4名が、著作権法違反幇助の疑いでスウェーデン当局に起訴されました。2009年4月17日、ストックホルム地方裁判所は4名全員に有罪判決を言い渡し、それぞれ1年の禁錮刑と、著作権者側への合計約2.7億円（3,000万スウェーデン・クローナ）の連帯賠償を命じました。

トラブルの構造と法的リスク

1. 「リンクを張っているだけ」は通用しない

The Pirate Bayはファイル自体をサーバーに保管せず、利用者同士をつなぐトレントファイル（リンク情報）を提供するだけの仕組みでした。運営者は「著作物そのものは扱っていない」と主張しましたが、裁判所は侵害行為を助長する事業として運営者の責任を認めました。

2. 摘発後も生き残り続けた「象徴」

有罪判決後もサイトはドメインを転々としながら運営が続けられ、世界各国で接続遮断（ブロッキング）措置の対象となりました。The Pirate Bayは、トレントを使った海賊版文化そのものの象徴として、著作権をめぐる国際的な議論で繰り返し引き合いに出される存在です。

[!CAUTION] リンクを提供するだけのサービスであっても、著作権侵害を助長する構造として設計されていれば刑事責任を問われます。「ファイルを保管していないから安全」という考え方は、世界的にも通用しません。
